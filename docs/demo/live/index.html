Live model inference, in this browser

This page loads the project's actual deployable model file (cnn_bilstm_int8.tflite, the same INT8 CNN-BiLSTM used everywhere else in the results) and runs it live, right now, in your browser via TensorFlow.js + WebAssembly — nothing here is precomputed or replayed. It's a stand-in for the on-device ESP32 inference until the hardware boards arrive.

This is a separate, focused proof that live in-browser inference works — it runs the model on one 50-sample sensor window at a time. It is not the scrubbing trace on the main demo page, which plays back longer precomputed traces (see the note there for why).
